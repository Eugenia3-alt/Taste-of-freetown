Taste of Freetown
A colorful, static multi-page restaurant website concept celebrating Sierra Leonean food and hospitality. This is a student project; sample menu items, prices, address, hours, and contact details are illustrative placeholders.

Pages
	•	index.html — Home
	•	about.html — About and restaurant story
	•	menu.html — Sample menu
	•	services.html — Restaurant services
	•	contact.html — Contact details and enquiry form demo

Project files
	•	style.css — Shared styles used by all pages
	•	images/ — Website photos, including food, drinks, services, and restaurant images

Keep style.css beside the HTML files. Keep image files inside the images folder, using the exact filenames referenced in the HTML or CSS.

View the website
	1.	Download or extract the project folder.
	2.	Keep all HTML files, style.css, and the images folder together.
	3.	Open index.html in a web browser.
	4.	Use the navigation links to visit the other pages.

  Adding the owner’s story and portrait
Add the owner profile section to about.html. Place the portrait in images/ (for example, images/owner.jpg) and use that relative path in the image’s src attribute. Use real biographical details only with the owner’s permission. If the restaurant is fictional, identify the story as part of the student concept.
